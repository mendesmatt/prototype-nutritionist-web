# Nutrition — Patient App

> Responsive web prototype for clinical nutritionists, with dietary plan presentation and day-to-day patient follow-up.

`HTML5` · `CSS3` · `JavaScript`

## 🇬🇧 English

**Segment:** Clinical nutrition & dietetics

Responsive web prototype for clinical nutritionists, with dietary plan presentation and day-to-day patient follow-up.

**Highlights**

- Food diary with a daily intake summary
- Dietary plan, shopping list and progress photos
- Direct chat with the nutritionist

**Tech:** HTML5, CSS3, vanilla JavaScript.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
